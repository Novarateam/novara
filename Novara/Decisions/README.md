# Decisions

## Purpose
This folder records strategic and operational decisions that matter to Novara's institutional memory.

## Record Standard
A decision note should make clear:
- source
- date
- evidence
- Novara interpretation
- confidence
- status
- unresolved questions
- CEO decision

## Current Policy
- Proposed does not become verified automatically
- Evidence must be external and traceable
- Company Memory and Company State remain operational
- Obsidian remains the human-readable knowledge layer
