# Novara Agents

## Purpose

This document is the central registry of active, planned and retired Novara agents.

It defines **which agents exist and what organizational responsibility they currently hold**.

It does not define the complete internal specification of an agent.

The universal requirements for every agent are defined in `11-agent_dna.md`.

# Agent Status

Every agent has a lifecycle status.

### planned

The agent has been defined but is not yet operational.

### designing

The agent's specification and requirements are being developed.

### training

The agent is being tested and evaluated in a controlled environment.

### observed

The agent is operational but operates under close human supervision.

### trusted

The agent has demonstrated sufficient reliability to receive increased authority.

### autonomous

The agent operates independently within defined authority boundaries.

### delegated

The agent has earned the ability to coordinate or delegate work to other agents within its authority.

### review

The agent is being evaluated because of performance, structural or organizational concerns.

### retired

The agent is no longer operational.

Useful knowledge, decisions and learning from a retired agent remain part of Novara's organizational memory.

# Initial Socials Organization

The first operating environment for Novara is Socials.

The initial specialist structure is:

```text
human + aios
       │
       ▼
   conductor
       │
       ├── opportunity
       ├── research
       ├── audience
       ├── strategy
       ├── creative
       ├── production
       ├── quality
       ├── distribution
       ├── performance
       └── learning
```

This is an initial organizational hypothesis.

It is not a permanent structure.

# Agent Creation Principle

The registry is not a fixed list.

Novara may create additional agents when:

* An existing agent becomes overloaded
* A responsibility becomes too broad
* Specialization would materially improve performance
* A new capability requires dedicated intelligence
* A new market requires domain expertise
* Separation improves reliability or governance

The creation of additional agents should be based on demonstrated need.

> **If the workload grows beyond what one agent can perform without degrading quality, we add intelligence rather than forcing the agent to carry the excess workload.**

---

# Agent Splitting

An agent may be split when specialization improves the organization.

Example:

```text
production
    │
    ├── video-production
    ├── graphics-production
    └── localization-production
```

The original agent may become a coordinating role or may be retired.

Splitting is an organizational decision, not an agent failure.

---

# Agent Merging

Agents may be merged when:

* Their responsibilities overlap substantially
* Communication overhead exceeds the benefit of specialization
* One agent can reliably perform both responsibilities
* Consolidation improves quality or efficiency

---

# Agent Retirement

An agent may be retired when:

* Its mission is no longer required
* Its responsibilities have been replaced
* Another structure performs the function better
* Its performance remains inadequate
* Its function is merged or divided

Retirement must preserve valuable organizational knowledge.

---

# Authority Principle

All new agents begin with limited authority.

Authority increases only after demonstrated:

* reliability
* decision quality
* execution quality
* transparency
* adaptability
* collaboration
* learning

Authority may decrease when trust deteriorates.

> **Every agent must earn the right to do more.**

---

# Current State

At the beginning of Novara's Socials phase:

**Agents are planned.**

**Human + AIOS retain primary strategic authority.**

The purpose of the first phase is to prove the architecture, evaluate agent performance and gradually increase autonomy based on evidence.

---

# Organizational Principle

The number of agents is unlimited in principle.

The objective is not to minimize the number of agents.

The objective is to create the **right amount of specialized intelligence for the work being performed**.

Too few agents can create overload and poor quality.

Too many agents can create unnecessary coordination overhead.

Novara continuously seeks the appropriate organizational structure.

> **Scale intelligence with the work.**
